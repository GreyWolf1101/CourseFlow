# 课序 CourseFlow

“课序”是一款原生 Android 周课程表应用，使用 Kotlin 与 Jetpack Compose 编写。

## 已实现

- 周一至周日七列同屏显示，首页以紧凑信息栏提示当前周与当天日期
- 点击首页周次可选择任意周，在课表区域通过跟手分页动画切换相邻周
- 星期标题下显示完整月/日日期，例如 `9/21`
- 单周、双周、每周课程规则，以及第 1—30 周学期配置
- 课程详情：教室、任课教师、时间、周数、备注
- 首页点击空白时段即可添加课程，自动预填星期、开始节次和正在查看的周；可调整课程名称、连续节数，并从 12 种协调配色中自由选择
- 首页空白时段不显示加号，点击课程可查看详情并删除；设置页支持选择多条课程删除或一键清空课表，保留学期和上课时间
- 第一周日期使用日历选择，并自动对齐到所选日期所在周的周一
- 默认提供 13 节课程时段至 23:00；每一节的开始时间和时长仍可单独修改
- 设置页提供文件导入、口令导入、生成分享口令，以及学期信息与上课时间配置
- 相同课程的相邻节次自动合并为连续卡片
- 导入 DOCX、XLSX、PDF、HTML/HTM、CSV、TXT；PDF 使用内置中文 ML Kit 模型离线 OCR
- HTML 支持星期矩阵、按列标记的课程列表及 rowspan/colspan 合并单元格，读取文字，不执行网页脚本
- 支持课序离线分享口令（包含课程、学期日期与上课时间）和 WakeUp 在线分享口令
- 导入预览支持逐条修改、删除，展示教师、教室、周数和首次上课日期；支持覆盖导入与追加导入、本地持久化
- 设置页检查 GitHub Release 更新，支持应用内下载、SHA-256 校验和系统安装器升级

旧版二进制 `.doc` / `.xls` 需要先在 Office 或 WPS 中另存为 `.docx` / `.xlsx`。不同学校的课表模板差异很大，导入器采用“表头 + 节次 + 元数据”的容错解析；无法确定的内容不会静默写入，而会在预览页显示提醒。

## 导入与日期核对

文件导入前请核对设置里的“第一周周一”。日期与星期冲突、周次倒置、超出学期范围的课程会跳过并提醒，不再自动截断为其他周次。周次支持 `1-4,7,9-12周` 和单双周。PDF 对有清晰表格线的七列课表先切分单元格再离线 OCR，避免星期串列；连续节次和周次优先读取单元格原文，合并换行的教师、场地字段，并用多处重复的教学班名称校对课程名。无固定时段的“其他课程”会提示手动补充。OCR 仍可能出现姓名错字，请在预览中核对。

导入预览可以直接输入并应用第一周周一（`yyyy-MM-dd`），所有显示日期随之重新计算。学年和打印日期不等于开学日期；文件学年与当前学期不符时会提醒。更改日期后仅允许覆盖导入，避免追加时改变已有课程日期。

课序口令在设置页生成并复制，无需服务器。WakeUp 支持粘贴完整分享文案或 32 位分享口令，需要联网连接 `api.wakeup.fun`，有效性取决于来源口令和服务可用性。兼容代码基于 WakeUp 6.x 分享协议，未取得真实有效口令时只能验证协议测试样例；服务协议变化可能需要更新适配。

口令的覆盖导入会同时应用来源学期和上课时间；来源日期或时段与当前课表不一致时禁用追加，防止现有课程整体错位。所有导入均先预览，点击课程行或编辑按钮可以修改后再保存。

WakeUp 协议中的加密兼容部分由 [WakeUpDecoder](https://github.com/airline233/WakeUpDecoder) 的 Apache-2.0 实现移植为 Kotlin，许可证随 APK 放在 `assets/licenses/WakeUpDecoder-LICENSE.txt`。HTML 读取使用 [jsoup](https://jsoup.org/cookbook/input/parse-document-from-string)。

## 构建

使用 Android Studio（JDK 17、Android SDK 35）打开项目，或运行：

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

调试 APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。

## 正式发布与更新

正式版使用专用证书签名。证书不进入 Git 仓库，本机默认从
`%USERPROFILE%/.courseflow-signing/signing.properties` 读取。

GitHub Actions 已配置为在推送 `v*` 标签时自动测试、签名并创建 Release。仓库需要设置：

- `KEXU_KEYSTORE_BASE64`
- `KEXU_STORE_PASSWORD`
- `KEXU_KEY_ALIAS`
- `KEXU_KEY_PASSWORD`

发布新版本前同时增加 `versionCode` 与 `versionName`，提交代码后推送对应标签，例如 `v1.1.0`。旧版本随后可在设置页直接发现并下载安装新版本。
